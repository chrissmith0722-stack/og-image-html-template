# OG Image HTML Template — Start here

**1200×630** Open Graph image starter in HTML/CSS for digital product share cards.

## Files

| File | Purpose |
|------|---------|
| `og.html` | Markup (title, sub, price, brand) |
| `og.css` | Layout sized for 1200×630 |
| `listing-gumroad.md` | Seller listing draft |
| `LICENSE` | MIT |

## Quick start

1. Open `og.html` in a browser.
2. Edit title / subtitle / brand / price.
3. Screenshot the `.canvas` at 1200×630 (or use a headless capture tool).
